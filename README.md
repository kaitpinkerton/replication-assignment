# replication-assignment

The paper I am using is "Voting rights and the resilience of Black turnout" by Kyle Raze. The paper uses 
CCES data from 2006-2019. I am using R 4.6.1. I am using the groundhog package to install a few packages, those being: 
tidyverse, haven, data.table, broom, fixest, and cowplot. The script that creates my replicated output is 
02-analysis-reproduce, which creates the LaTex code to create the table. The original data from CCES
is too large to upload to GitHub, so it will be linked in this README: 
https://dataverse.harvard.edu/file.xhtml?fileId=4101304&version=5.0
